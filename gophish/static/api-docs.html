Black Cat API Documentation

Automate this tool over its JSON API: pull reports, launch campaigns and manage every object without opening the GUI.

Introduction

Black Cat exposes the full management API under /api on the admin listener (default https://127.0.0.1:3333/api). Everything the GUI does — campaigns, groups, templates, profiles, users — is a JSON call you can script.

Is Python your language of choice? There is a community Python API client that wraps these endpoints and makes automation a piece of cake.

Use Cases

  • Custom reporting: pull campaign results as JSON and build reports in Excel or any BI tool.
  • Full automation: create templates, groups and campaigns from scripts and run phishing simulations on a schedule.
  • Continuous testing: rotate targets and pretexts programmatically across the year.

Authorization

Find your key under System > Account Settings in the GUI. Send it with every request, either as a query parameter or as a bearer token:

curl -k "https://127.0.0.1:3333/api/campaigns/?api_key=YOUR_KEY"

curl -k -H "Authorization: Bearer YOUR_KEY" \
  https://127.0.0.1:3333/api/campaigns/
Treat the key like a password. Anyone holding it has the same power as your GUI login. Use HTTPS (the default) so it never travels in clear text.

Responses

Successful calls return JSON objects (or arrays for collections). Timestamps use YYYY-MM-DDTHH:MM:SSZ format. Failures return an error payload with the matching HTTP status code.

Status Codes

CodeMeaning
200 OKRequest succeeded (GET, PUT, DELETE, actions).
201 CreatedObject created (POST).
400 Bad RequestMalformed JSON or missing required fields.
401 UnauthorizedMissing or invalid API key.
403 ForbiddenValid key, but the account lacks permission (admin-only routes).
404 Not FoundNo object with that id.

Campaigns

MethodEndpointDescription
GET/api/campaigns/List campaigns.
POST/api/campaigns/Create (and launch) a campaign.
GET/api/campaigns/summaryAggregate stats.
GET/api/campaigns/{id}Get one campaign.
PUT/api/campaigns/{id}Update a campaign.
DELETE/api/campaigns/{id}Delete a campaign.
GET/api/campaigns/{id}/resultsPer-target events timeline — opens, clicks, submissions, captured sessions.
GET/api/campaigns/{id}/summaryCounts per status.
GET/api/campaigns/{id}/completeMark a campaign complete.
GET/api/sms_campaigns/List SMS campaigns (same sub-actions as email campaigns).

Users & Groups

MethodEndpointDescription
GET/api/groups/List target groups.
POST/api/groups/Create a group with targets (first/last name, email, position).
GET/api/groups/summaryGroup stats.
GET/api/groups/{id}Get one group.
PUT/api/groups/{id}Update a group.
DELETE/api/groups/{id}Delete a group.
GET/api/groups/{id}/summaryStats for one group.
For SMS targets, put the phone number in the email field of each target in an accepted Twilio format.

Templates

MethodEndpointDescription
GET/api/templates/List email/SMS templates.
POST/api/templates/Create a template (text for SMS, html for mail).
GET/api/templates/{id}Get one template.
PUT/api/templates/{id}Update a template.
DELETE/api/templates/{id}Delete a template.

Sending Profiles

MethodEndpointDescription
GET/api/smtp/List email sending profiles.
POST/api/smtp/Create an SMTP profile (host, user, pass, headers).
GET/api/smtp/{id}Get / update / delete one profile (GET, PUT, DELETE).
GET/api/sms/List Twilio SMS profiles.
POST/api/sms/Create an SMS profile (Twilio SID, token, number).
GET/api/sms/{id}Get / update / delete one SMS profile (GET, PUT, DELETE).

Users & Webhooks (admin)

These routes need an administrator API key:

MethodEndpointDescription
GET/api/users/List users (POST creates).
GET/api/users/{id}Get / update / delete one user.
GET/api/webhooks/List event webhooks.
GET/api/webhooks/{id}/validateTest-fire a webhook.

Utilities & Import

MethodEndpointDescription

Examples

List campaigns

curl -k -H "Authorization: Bearer YOUR_KEY" \
  https://127.0.0.1:3333/api/campaigns/

Create a campaign

{
  "name": "Q3 Finance Pretext",
  "template": {"name": "Invoice Lure"},
  "url": "https://login.example.com/Ab3x9Q21",
  "smtp": {"name": "Relay"},
  "groups": [{"name": "Finance"}],
  "launch_date": "2026-09-20T09:00:00Z"
}

Pull results for reporting

curl -k -H "Authorization: Bearer YOUR_KEY" \
  https://127.0.0.1:3333/api/campaigns/1/results

Black Cat Notes

  • Set the campaign url to your lure URL (Infrastructure > Lures > get URL), not to the GoPhish landing server — the phishing server on port 8080 is unused.
  • Proxy captures surface inside /results as Captured Session events with credentials and token counts.
  • The Infrastructure panel (phishlets, domain/SSL, lures, loot) is GUI-only and has no API — manage it from the dashboard.
