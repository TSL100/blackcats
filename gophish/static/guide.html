Black Cat User Guide

The single-tool manual for your phishing operations: mailer, tracker and adversary-in-the-middle proxy in one dark dashboard.

Introduction

Black Cat unifies two tools into one GUI: a mailer & tracker (campaigns, templates, groups, sending profiles) and an adversary-in-the-middle proxy (the Infrastructure section) that relays logins to the real sites while capturing credentials and session tokens — including through 2FA/MFA flows.

The combination workflow is simple:

  1. Prepare the Infrastructure (domain, certificates, phishlets, lures).
  2. Build the campaign (template + sending profile + group) with the lure URL as the landing page.
  3. Launch, track opens/clicks on the Dashboard, and collect credentials and tokens from Sessions.

Getting Started

  1. Start the server from the gophish folder:
    ..\evilgophish.exe serve -config config.json
  2. Open the admin GUI at https://127.0.0.1:3333 and sign in (default admin / gophish — change it under System > Account Settings).

Dashboard

The landing page after login. It shows aggregate charts (sent, opened, clicked, submitted data, captured sessions, reported) plus a Recent Campaigns table with per-campaign status. Use View All to jump to the full campaign list.

Email Campaigns

Campaigns > Email Campaign lists active and archived campaigns. New Email Campaign asks for:

  • Name — internal label for the engagement.
  • Email Template — the lure mail. Put the generated lure URL in as the landing page.
  • evilginx URL — the full lure URL targets open (must be reachable by them).
  • QR Code Size — optional; leave blank for normal links, or set e.g. 256 to embed QR images via the {{.QR}} template variable.
  • Launch Date / Send By — schedule the send window.
  • Sending Profile & Groups — who sends it and who receives it.
Use Send Test Email from the campaign dialog to verify deliverability before launch.

SMS Campaigns

Campaigns > SMS Campaign sends text campaigns through Twilio:

  1. Create the message under Assets > Email/SMS Templates using Text only (no tracking link inside the SMS body; leave envelope sender and subject blank).
  2. Configure the sender under Assets > SMS Sending Profiles with your Twilio number, Account SID and Auth Token.
  3. Import the group CSV keeping the standard column names, with target phone numbers in the Email column in an accepted Twilio format.
  4. Launch with the lure URL as the landing page, exactly like an email campaign.

Templates & Sending Profiles

Assets holds the reusable building blocks: mail/SMS templates, email sending profiles (SMTP) and SMS sending profiles (Twilio). Anything you create here is selectable when launching a campaign. Keep templates realistic, branded to the pretext, and always test-render them before launch.

Infrastructure

The Infrastructure menu is the proxy control center — the same login, no separate tool. Recommended order:

  1. Overview — engine status at a glance (domain, IPs, ports, counts).
  2. Domain & SSL — base domain, external IP, certificates.
  3. Phishlets — hostnames on, phishlets enabled.
  4. Lures — lure paths created, phishing URLs generated.
  5. Sessions — captured loot reviewed.

Phishlets

Each phishlet impersonates one site. Give it a hostname (a subdomain of your base domain), Save, then Enable. The State badge shows what is live. The landing URL column shows where victims land.

New Phishlet (auto-generate)

Enter a Target domain and hit Discover & generate: the tool inspects the site's login page and drafts a starting phishlet scaffold for review. Always verify hosts, cookies and credential keys before use.

Domain & SSL

  1. Set the Base domain (DNS must point at this server) and the External IP, then Save settings.
  2. Press Sync certificates now. Issuance can take up to a minute — watch the server log.
  3. The table shows live per-hostname status: serving / not serving and valid / missing with expiry.
A hostname showing missing usually means DNS is not reaching this server yet, or an ACME rate limit — check the server log after a sync.

Sessions (Loot)

Every victim that completes a login creates a session row: phishlet, network address, captured credentials, custom fields (e.g. password-reset flows), token counts and timestamps. Expand full JSON for the complete capture including cookies usable for session replay.

Captures are also written to the shared database, so they surface as Captured Session events in the campaign results — match them by time and landing URL.

Lures & Phishing URLs

A lure binds a phishlet to a path (and optionally its own hostname and redirect URL). Create one per campaign link, then use get URL with the recipient's rid to build their personal phishing link.

The rid is encrypted into the URL, so clicks and captures tie back to the right result row in the campaign. Optional extra parameters accept whitespace-separated key=value pairs merged into the payload.

https://login.example.com/Ab3x9Q21?rid=ENCRYPTED_PAYLOAD

Tips & Troubleshooting

  • Test like a victim: use one recipient and an incognito window. The proxy pins a session cookie per browser — re-testing many links in one browser confuses tracking.
  • "404 page not found" on proxy links: the proxy engine is not running. Restart the server and check the log for startup errors.
  • Certificate stuck on missing: verify DNS, the external IP setting, and port 443 reachability, then sync again.
  • Ports 443/53 busy: run as Administrator and stop conflicting services (IIS, Skype, other DNS).
  • Config paths: the proxy directories in config.json must exist on disk, otherwise startup fails trying to create them.

FAQ

Where do phishing links point — GoPhish or the proxy?

Always the proxy lure URL. GoPhish sends the mail and tracks opens/clicks; landing pages live on the proxy. The GoPhish phishing server on port 8080 is not used.

How do captures link back to recipients?

Through the encrypted rid in each personal URL. Keep it in the link when you paste it into the template.

Can I re-test a link myself?

Yes, once per fresh incognito session. Clear state between tests or you will pollute the victim's result row.
